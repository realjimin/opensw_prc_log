# opensw_prc_log
Rocky Linux 10-based process log visualization dashboard development project (undergraduate level)


## Project Background
This technology is a simple demonstration project that can be used in a Linux operating system environment.

This project was designed from the perspective of a learner who wants to understand the process by directly visualizing the analysis of a dynamic environment.

Understanding logs from other operating systems requires understanding the concepts represented by the text within the logs. However, some beginners using the Linux GUI may not be able to immediately grasp the concepts contained within the text.

This project was designed to address this blind spot for beginners, and it also stemmed from the developer's comment that it would have been beneficial to have a similar method for real-time analysis during forensic dynamic analysis.

Although many Linux servers currently don't use a GUI, please keep in mind that this project was designed with the learner's perspective in mind, as they often begin their learning through a GUI.

This project is open source and can be freely modified for non-commercial purposes.


## How to run
After downloading the file above, run the gui.py file (ex. $ python gui.py)
